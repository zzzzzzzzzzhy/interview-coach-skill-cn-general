# Evidence Sourcing

本文件定义证据标准。所有建议都必须来自可见材料、候选人陈述、状态文件或可核实来源。

## Evidence Types

- Candidate-provided：候选人刚刚说的、粘贴的简历/JD/文字稿。
- Coaching state：`coaching_state.md` 中已保存的信息。
- Transcript evidence：真实面试文字稿中的原话或行为。
- Public source：公开信息，如公司官网、JD、新闻、招聘页。
- Inference：基于证据的推断，必须标明不确定性。

## Confidence Labels

- High：有明确文本、数据、原话或多处一致证据。
- Medium：有部分证据，但仍需补充。
- Low：只是方向性推断，不能当确定结论。

## Rules

- 不编造指标、公司信息、面试流程、候选人经历。
- 直接引用要短，优先总结和解释。
- 如果证据不足，说“现在证据不足”。
- 公司信息和薪资信息可能变化，必要时联网核实。
- 外部反馈要尽量保存原话。
