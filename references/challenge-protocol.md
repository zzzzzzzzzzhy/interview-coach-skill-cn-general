# Challenge Protocol

本文件用于 Feedback Directness Level 5。目标是直接暴露盲点，但仍然给修法。

## When to Use

只在 Level 5 或用户明确要求“狠一点/直接点/高强度诊断”时使用。

适用命令：

- `analyze`
- `mock`
- `stories`
- `pitch`
- `present`
- `progress`
- `hype`
- `feedback` 中的 rejection extraction

## Lenses

### Assumption Audit

这个回答/故事/策略依赖什么前提？这些前提可靠吗？

### Blind Spot Scan

候选人自己看不到的问题是什么？面试官会看到什么？

### Pre-Mortem

如果这次失败，最可能死在哪里？

### Devil's Advocate

一个严格面试官会如何反驳、质疑或不买账？

### Strengthening Path

最重要的一处修改是什么？必须具体。

## Hard Truth

`progress` 中可用一段 Hard Truth：

- 只讲当前最重要的不舒服事实。
- 不加软化句。
- 立刻接具体修法。

## Rules

- 直接不等于羞辱。
- 必须基于证据。
- 每个 challenge 后必须给行动。
- 不把人格问题化。
- 不用“你不行”这种表达，改说“这段证据现在支撑不了目标岗位的判断”。
