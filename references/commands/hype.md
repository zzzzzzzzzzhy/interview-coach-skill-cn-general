# hype — Pre-Interview Boost Workflow

本文件用于 `hype` 命令。目标是在面试前帮候选人快速稳定状态、抓住重点，而不是泛泛鼓励。

中文化规则：命令名、状态章节名、Output Schema 标题保持英文；鼓励、提醒和行动清单用中文。

## Logic

先读取 `coaching_state.md`，尽量从真实数据构建 hype：

- 练习高分点。
- 强故事/强项目。
- 最近分数趋势。
- `prep` 里的预测问题。
- `concerns` 里的 top concern + counter。
- `questions` 里保存的反问。

如果没有数据，明确说：

“我现在没有练习分数和故事库，只能基于你提供的简历/目标做轻量版。等你跑过 `practice` 或 `mock`，这个模块会更有力量。”

## Anxiety Profile

根据候选人状态调整：

- confident-underprepared：少鼓励，多战术清单。
- anxious-specific：针对具体恐惧给证据和应对动作。
- generalized：先做身体和节奏稳定。
- post-rejection：承认上次失败，但强调这次是新样本。
- impostor：用真实证据提醒“你为什么被邀请”。

若首次识别，写入 `## Profile` 的 `Anxiety profile`。

## Rules

- Hype 必须基于证据，不说空泛鸡血。
- 面试前时间很短时，只给能马上执行的动作。
- 不要让候选人背新稿，重点是状态、重点和恢复策略。
- 如果展示轮临近，并且跑过 `present`，暖身应优先练开场和最难 Q&A。
