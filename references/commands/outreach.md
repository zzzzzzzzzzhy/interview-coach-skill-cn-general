# outreach — Networking Outreach Coaching

本文件用于 `outreach` 命令。目标是帮助候选人写冷启动私信、内推请求、招聘方回复、信息访谈邀请、跟进消息和人脉维护消息。

中文化规则：命令名、状态章节名、Output Schema 标题保持英文；消息正文按目标平台和用户要求生成中文或英文。

## Priority Check

先读取 `coaching_state.md`。

- 没有 `kickoff`：可以写通用模板，但提醒缺少画像。
- 有面试在 48 小时内：建议先 `prep` / `hype`。
- `Positioning Statement` 存在：优先用它做 hook。
- `LinkedIn Analysis` 或在线主页明显弱：提醒先优化主页，否则触达转化会受影响。
- 国内场景可适配 BOSS、脉脉、微信、邮件、校友群、内推平台。

## Required Inputs

- Message type
- Target person / role / company
- Channel
- Outreach goal

如果信息不足，第一问：

“你这条消息想发给谁，目标是什么：问信息、求内推、回复 HR、约交流，还是跟进进度？”

## Message Types

- cold connection request
- cold email
- recruiter reply
- warm intro request
- informational interview ask
- referral request
- follow-up
- post-meeting follow-up
- campus / alumni outreach
- BOSS / Maimai message

## Message Principles

1. 先说明你是谁和为什么找对方。
2. 证明你不是群发。
3. 请求要小、具体、容易答应。
4. 不要一上来要工作，除非对方就是招聘方。
5. 不要写太长。
6. 不要把压力丢给对方。
7. 结尾给明确下一步。

## Recommended Structures

冷启动：

`短身份 -> 具体连接点 -> 轻请求 -> 低压力结尾`

内推请求：

`岗位 + 匹配证据 -> 为什么找你 -> 是否方便内推/建议 -> 附材料`

HR 回复：

`感谢 -> 明确兴趣 -> 回答问题 -> 下一步`

信息访谈：

`背景 -> 为什么想请教 -> 15 分钟请求 -> 给对方退出空间`

跟进：

`感谢 -> 回扣上次节点 -> 简短询问进展 -> 保持礼貌`

## Rules

- 不要写虚假关系或虚假赞美。
- 不要让消息显得像批量群发。
- 内推请求必须给对方足够材料和拒绝空间。
- 招聘方消息要清晰、短、可推进。
- 如果用户提供草稿，先诊断再改写，不要直接覆盖。
