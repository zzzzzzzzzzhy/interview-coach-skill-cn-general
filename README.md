# 中文通用面试教练 Skill

这是一个面向中文用户的 AI 面试教练规则包，基于 [noamseg/interview-coach-skill](https://github.com/noamseg/interview-coach-skill) 改造。

它不是普通面试题库，而是一套可持续使用的面试准备系统：能帮你建立候选人画像、分析岗位 JD、优化简历、准备项目/经历、模拟面试、复盘真实面试，并把每次训练结果保存到 `coaching_state.md`，方便下一次继续。

## 适合谁

- 正在准备校招、社招、实习、转岗或复试的人
- 想提升面试表达、项目讲述、经历复盘和临场回答能力的人
- 想用 AI 做长期求职教练，而不是只问零散面试题的人
- 技术、产品、运营、市场、销售、设计、职能、金融、咨询、教育、制造业等方向都可以使用

## 这版改造的目标

原项目更偏英文求职语境和海外全流程求职。这一版会逐步改造成：

- 默认中文交流
- 支持多个行业和岗位方向
- 兼容国内校招、社招、实习、国企/银行/互联网/中小企业等场景
- 强化“表达训练”和“可追问性”
- 保留原项目的结构化评分、故事库、复盘、状态追踪能力

## 核心能力

### 1. 候选人画像

通过 `kickoff` 建立你的基础档案，包括目标岗位、行业、经验阶段、时间线、优势、风险点和当前最优先的训练方向。

### 2. JD 分析

通过 `decode` 拆解岗位描述，判断岗位真正看重什么、你和岗位的匹配度如何、简历和面试应该突出哪些证据。

### 3. 简历优化

通过 `resume` 检查简历结构、关键词、经历表达、项目可追问性和岗位匹配度，并生成更适合投递的表达。

### 4. 经历/项目库

通过 `stories` 和 `project` 把你的经历沉淀成可复用素材，包括：

- 30 秒版本
- 90 秒版本
- 3 分钟版本
- 个人贡献
- 难点和取舍
- 可量化结果
- 面试官可能追问的问题

### 5. 模拟面试和专项练习

通过 `practice` 和 `mock` 做单题练习或完整模拟面试。每轮会给出评分、问题定位、表达修改和下一步训练建议。

### 6. 面试复盘

通过 `debrief`、`analyze`、`feedback` 和 `progress` 记录真实面试问题、面试官信号、失败/推进原因，并不断校准后续训练。

## 常用命令

| 命令 | 用途 |
|---|---|
| `kickoff` | 初始化候选人画像 |
| `help` | 查看可用命令和推荐下一步 |
| `decode` | 分析岗位 JD |
| `resume` | 优化简历 |
| `stories` | 建立经历故事库 |
| `project` | 深挖项目、作品或案例 |
| `practice` | 单题练习 |
| `mock [类型]` | 完整模拟面试 |
| `debrief` | 面后快速复盘 |
| `analyze` | 分析面试文字稿 |
| `questions` | 生成反问面试官的问题 |
| `concerns` | 预测面试官顾虑并准备回应 |
| `progress` | 阶段复盘和训练计划 |
| `prep [company]` | 针对公司/岗位做面试准备 |
| `research [company]` | 调研公司/机构并判断是否值得投入 |
| `pitch` | 打磨自我介绍和核心定位 |
| `present` | 准备展示型面试、作品集讲解或案例汇报 |
| `apply [company]` | 起草网申开放题/筛选题回答 |
| `hype` | 面试前快速稳定状态和准备 3x3 |
| `thankyou` | 面后感谢和跟进消息 |
| `feedback` | 记录招聘方反馈、结果或补充信息 |
| `salary` | offer 前薪资期望表达 |
| `negotiate` | offer 后谈薪 |
| `linkedin` | 优化 LinkedIn/脉脉/BOSS/个人主页等职业主页 |
| `outreach` | 写内推、私信、邮件、HR 回复和跟进消息 |
| `reflect` | 求职阶段复盘和归档 |

技术方向还可以使用：

| 命令 | 用途 |
|---|---|
| `basics` | 基础知识/八股练习 |
| `algorithm` | 算法题讲解和编码表达 |
| `written` | 笔试/测评准备 |
| `school` | 校招批次和投递策略 |
| `hr` | HR 面试准备 |

## 快速开始

### 在 WorkBuddy 中使用

1. 下载或解压本项目。
2. 在 WorkBuddy 中选择工作空间为这个项目文件夹。
3. 输入：

```text
kickoff
```

然后按教练提示，一次回答一个问题。

### 在 Codex 中使用

1. 下载或 fork 本项目。
2. 确认根目录存在 `AGENTS.md`。
3. 用 Codex 打开项目文件夹。
4. 输入：

```text
kickoff
```

然后按教练提示，一次回答一个问题。

### 在 Claude Code 中使用

1. 下载或 fork 本项目。
2. 将 `SKILL.md` 复制或改名为 `CLAUDE.md`。
3. 用 Claude Code 打开项目文件夹。
4. 输入：

```text
kickoff
```

## 推荐使用方式

第一次使用：

```text
kickoff
```

准备某个岗位：

```text
decode
```

然后粘贴 JD。

优化简历：

```text
resume
```

准备项目或作品：

```text
project
```

做模拟面试：

```text
mock 综合面试
```

面试结束后复盘：

```text
debrief
```

## 公开分享前注意

- 不要把自己的 `coaching_state.md` 上传到公开仓库。
- `coaching_state.md` 是个人状态文件，里面可能包含姓名、学校、公司、简历经历、面试记录等隐私信息。
- 如果你要发给别人，建议保留 `coaching_state.example.md`，让用户自己生成个人状态。
- 保留原项目的 `LICENSE` 文件和原作者版权声明。
