# v2 Release Notes

本文件保留为历史版本说明。中文版通用版不逐字翻译上游 changelog，而是记录本仓库当前可理解的能力演进。

## 核心方向

v2 代表原项目从基础面试教练扩展到更完整的求职流程：

- 更完整的故事库管理。
- 更细的面试分析。
- 更系统的练习流程。
- 更强调状态文件 `coaching_state.md` 的长期连续性。
